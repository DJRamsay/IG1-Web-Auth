6. Hyperlinks

Type of link Example Code used
Bookmark on the same page Jump to the prices table <a href="#tables">
Another page on this website (relative path) Our accommodation <a href="page2.html">
A bookmark on another page Room types on page 2 <a href="page2.html#rooms">
External website in a NEW window/tab Cambridge International <a href="https://..." target="_blank">
External website in the SAME window SA Astronomical Observatory <a href="https://..." target="_self">
Open in a NAMED window Open page 2 in a window called "lodgeinfo" <a href="page2.html" target="lodgeinfo">
Send an email (with a subject line) Email our bookings team <a href="mailto:bookings@...?subject=Tour%20booking">
Image as a link <a href="index.html"><img ...></a>

Exam note: a named window (for example target="lodgeinfo") opens a new window the first time. Every later link with the same target name reuses that window instead of opening another one. In an email link, spaces in the subject are written as %20.

Relative and absolute file paths

A relative path such as images/logo.svg describes where a file is from the current page. An absolute path such as C:\Users\Sam\Website\images\logo.svg or a full web address gives the complete location.

Always use relative paths for files inside your own website. An absolute path to your own hard drive will not exist on the web server or on anyone else's computer, so the image or link will break when the site is uploaded.

7. Styles: external, internal and inline

A web page has three layers:

  • Content layer: the HTML that structures the page (text, tables, images, links).
  • Presentation layer: the CSS that controls how it looks (colours, fonts, spacing).
  • Behaviour layer: scripts such as JavaScript that make it interactive.

The cascade in action

All three paragraphs below use the same class. Each one has been overridden by a different kind of style.

1. External stylesheet only: the colour comes from styles.css.

2. Internal style: the style tag in the head overrides the external file.

3. Inline style: the style attribute beats everything else.

Type of style Where it is written Priority
Inline Inside the HTML tag using style="..." Highest
Internal (embedded) In a <style> tag in the head section Middle (when placed after the link to the external file)
External In a separate .css file attached with <link> Lowest

Why use an external stylesheet? One file controls every page, so the whole website has a consistent look. A change made once in the stylesheet updates every page, and the HTML files stay smaller and easier to read.

8. Practice task (past-paper style)

You are going to edit a web page for Karoo Skies.

  1. Open the file tours.html in a text editor.
  2. Place the text Karoo Skies Tours so that it is displayed in the browser tab.
  3. Attach the stylesheet ks_style.css to the web page.
  4. Set the default target window to _blank.
  5. Create a table with 3 rows and 2 columns. Merge the two cells in the top row. Set the table width to 80% of the window.
  6. Place the image ks_logo.jpg in the top row. Resize it to 150 pixels wide, maintaining the aspect ratio.
  7. Make the text Contact us a hyperlink that sends an email to info@karooskies.example with the subject Tour enquiry.
  8. Make the image a hyperlink to https://www.saao.ac.za that opens in a new window called _skies.

Model answer

<!DOCTYPE html>
<html>
<head>
  <title>Karoo Skies Tours</title>
  <link rel="stylesheet" href="ks_style.css">
  <base target="_blank">
</head>
<body>
  <table style="width: 80%;">
    <tr>
      <td colspan="2">
        <a href="https://www.saao.ac.za" target="_skies">
          <img src="ks_logo.jpg" alt="Karoo Skies logo" width="150">
        </a>
      </td>
    </tr>
    <tr>
      <td></td>
      <td></td>
    </tr>
    <tr>
      <td><a href="mailto:info@karooskies.example?subject=Tour%20enquiry">Contact us</a></td>
      <td></td>
    </tr>
  </table>
</body>
</html>

Common mistakes that lose marks: using an absolute path to the image or stylesheet; setting both width and height so the image distorts; forgetting the alt attribute; misspelling a target name (_skies is not the same as skies); and placing the title or stylesheet link in the body instead of the head.
